# ВидеоКласс

Готовый сайт для учебных видео. Учитель загружает видео и получает отдельную ссылку. Ученик вводит фамилию, имя и класс, смотрит материал, а сайт сохраняет прогресс.

## Что уже работает

- закрытый вход учителя по электронной почте и паролю;
- загрузка больших видео с продолжением после обрыва связи;
- публикация и скрытие видео;
- отдельная ссылка на каждое видео;
- фиксация просмотренной доли, реального времени, максимальной скорости, пауз и перемоток;
- статусы «Досмотрел(а)», «Частично», «Быстро», «Начал(а)»;
- поиск и фильтры по результатам;
- выгрузка таблицы в CSV, который открывается в Excel;
- адаптация для телефона, планшета и компьютера;
- закрытое хранилище видео и защита результатов правилами доступа.

Система фиксирует воспроизведение в браузере, но не может доказать, что ученик всё время смотрел на экран.

## Подключение базы и хранилища

1. Создайте проект на [Supabase](https://supabase.com/dashboard).
2. Откройте **SQL Editor**, вставьте всё содержимое файла `supabase.sql` и выполните запрос.
3. Откройте **Authentication → Users** и создайте пользователя учителя с электронной почтой и надёжным паролем. Скопируйте его UUID.
4. В **SQL Editor** выполните запрос, заменив значение на скопированный UUID:

   ```sql
   insert into public.teachers(user_id) values ('UUID_УЧИТЕЛЯ');
   ```

5. В настройках проекта найдите **Project URL** и публичный **Publishable/anon key**.
6. Откройте `config.js` и замените `YOUR_SUPABASE_URL` и `YOUR_SUPABASE_ANON_KEY`. При желании измените `siteName`.

Секретный `service_role` key на сайт добавлять нельзя. Нужен только публичный Publishable/anon key; ограничения задаются правилами из `supabase.sql`.

## Публикация по интернет-ссылке без GitHub

Самый простой способ — ручная публикация через [Netlify Drop](https://app.netlify.com/drop):

1. Распакуйте архив `VideoKlass-site.zip` на компьютере.
2. Сначала выполните настройку Supabase выше и внесите Project URL и публичный ключ в `config.js` внутри папки `video-class`.
3. Войдите в Netlify или создайте бесплатный аккаунт.
4. Откройте [app.netlify.com/drop](https://app.netlify.com/drop).
5. Перетащите в область загрузки именно распакованную папку `video-class`, внутри которой сразу находится `index.html`.
6. После загрузки появится адрес, заканчивающийся на `.netlify.app`. Его можно отправлять ученикам.

При обновлении сайта снова перетащите обновлённую папку в область ручной публикации вашего проекта. Пароли и секретный `service_role` key в файлы добавлять нельзя.

Также проект можно разместить на любом хостинге статических сайтов. GitHub не требуется.

## Первый запуск

1. Откройте `admin.html` на опубликованном сайте.
2. Войдите под учительской почтой и паролем.
3. Нажмите **Добавить видео** и дождитесь 100% загрузки.
4. Выберите видео и нажмите **Скопировать ссылку**.
5. Отправьте ссылку ученикам.

## Как считается просмотр

- Время засчитывается, когда видео воспроизводится и вкладка сайта открыта на экране.
- Процент считается по уникальным просмотренным отрезкам, поэтому повтор одного места не увеличивает результат свыше его длительности.
- При результате от 90% ставится статус «Досмотрел(а)».
- Скорость выше 1,25× или слишком малое реальное время относительно просмотренных отрезков помечается как «Быстро».
- Перемотки и максимальная скорость отображаются отдельно, чтобы учитель мог сам оценить результат.

## Работа с персональными данными

Сайт собирает сведения об учениках, поэтому перед использованием согласуйте его с правилами школы и собирайте только необходимые данные. Результаты не следует публиковать или передавать посторонним. Для школьного использования рекомендуется периодически удалять старые записи в соответствии с внутренними правилами хранения.
